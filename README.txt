NAINA SHARMA PORTFOLIO

Live portfolio: https://nikhilbhatia96010-alt.github.io/Portfolio/

Open index.html in a modern browser to view the portfolio. Keep Naina_Sharma_Resume.pdf in the same folder so the Download Resume links work.

The site preserves the supplied single-page portfolio design and interactive navigation. Tailwind CSS, Google Fonts and Font Awesome load from their public CDNs, so an internet connection is needed for those remote assets.

The contact form opens a pre-addressed email draft in the visitor's default email application; it does not submit to a server.
